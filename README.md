## Ответы на вопросы
### 1. Чем int.TryParse() безопаснее int.Parse()? В каких случаях стоит использовать каждый?
int.Parse() при вводе текста (например, abc) падает с ошибкой — программа вылетает.
int.TryParse() не падает: если ввод неправильный, он просто возвращает false, и программа продолжает работать.
### 2. Когда switch удобнее, чем цепочка if/else if? Приведите пример из реальной жизни.
switch удобнее, когда одну переменную сравнивают с конкретными значениями —  пункт меню, день недели, номер месяца или арифметическая операция.
Если бы это писали через if/else if, получилась бы длинная цепочка из трёх-четырёх условий — читать сложнее. А switch сразу показывает: «вот варианты, вот что делать».
Пример из реальной жизни — меню в игре. Игрок выбирает:
1 — играть
2 — настройки
3 — выйти

### 4.Чем отличается = от == в C#? Почему это частая ошибка?
=  присваивание. x = 5; - положить 5 в x.
==  сравнение. x == 5 - проверить, равно ли x пятёрке (даст true или false).
